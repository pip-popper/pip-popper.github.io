使い方

  1. 左の一覧から、直したい曲・アルバム・ページを選びます。
  2. 文字を直して 保存 を押します（この時点ではまだ公開されません）。
  3. プレビュー で、実際のページと同じ見た目で確認します。
  4. よければ上の 公開する を押し、内容を確認して公開します（1〜3分で公式サイトに反映）。
  5. 間違えたときは、公開前なら 変更を破棄、公開後なら 公開履歴・取り消し から元に戻せます。

自分で直せるもの（左の一覧から選ぶ）

  • 曲：曲名・歌詞・紹介文・制作背景・配信リンク（Spotify・YouTube・Suno・Apple Music）
  • HISTORY・その他の作品：作品名・制作秘話・紹介文・曲目の曲名・参加者・年・注記など、ページに出ている文字
  • サイトの文言：トップの一文、ヒストリー／その他の作品の見出し・説明文・末尾の文、アーティスト紹介、メッセージ欄の説明文、音源非公開の曲ページの文

固定（変更はAIに依頼）

  • ページの構成・デザイン・演出、アルバムの特設デザインと画像
  • メニュー・ボタン・欄の名前、メッセージの送信フォーム
  • 曲・アルバムの追加・削除・並び順、公開日（今後の版で対応予定）、上記以外のリンク
  • PRIVATE（音源）はPRIVATEの管理画面で操作

左の一覧のいちばん下にも「固定（変更はAIに依頼）」を表示しています。変更したいときは、Claude Code などのAIに「〇〇を変えたい」と依頼してください。
