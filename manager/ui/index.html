使い方

  1. やりたい作業は、左上の 管理メニュー から選びます（新曲・アルバムの登録、下書きの続き、公開状況、PRIVATEの音源・歌詞・パスワード、公開履歴）。公開済みの曲・アルバム・ページを直すときは、その下の一覧（たたんである見出しを押すと開く）から選びます。
  2. 直して 保存 を押します（この時点ではまだ公開されません）。
  3. プレビュー で、実際のページと同じ見た目で確認します。
  4. よければ上の 公開する を押し、内容を確認して公開します（1〜3分で公式サイトに反映）。
  5. 間違えたときは、公開前なら 変更を破棄、公開後なら 公開履歴・取り消し から元に戻せます。

新しい曲・アルバムを載せる

  1. 管理メニューの「＋ 新曲を登録」／「＋ アルバムを登録」で、曲名やアルバム名・ジャケット画像（PNG/JPEG）・歌詞・AIの感想・紹介文・制作秘話・収録曲（曲順）を入れて「確認して保存」。何度でも保存でき、「保存履歴・復元」で前の版に戻せます（ここまでは下書き。公開されません）。
  2. 新曲は公開区分（一般公開／このサイトのみ／PRIVATEのみ）と、歌詞・AIの感想の公開範囲を決めます。「掲載イメージを見る」で確認できます。
  3. 登録状態は「下書き」と「公開準備完了」の2つだけです（どちらにしても、まだ公開されません）。載せてよくなったら「公開準備完了」にして保存 → 画面下の「公式HPの掲載データへ取り込む」（ページのURL名を英小文字で決める）。「公開済み」は、実際に公式サイトに出たときに自動で表示されます。途中の登録は管理メニューの「下書き・登録中の曲とアルバム」から開けます。
  4. 上の「プレビュー」で確認して「公開する」。

自分でできること

  • 新曲・新しいアルバムの登録（下書き・保存履歴・復元・プレビュー・公式HPへの取り込み・公開）
  • 曲：曲名・よみがな（あいうえお順用）・歌詞・AIの感想（紹介文）・制作背景・配信リンク（Spotify・YouTube・Suno・Apple Music）
  • アルバム（HISTORY・その他の作品）：ページに出ている文字、掲載順（同じページの中で前へ／後ろへ）、収録曲の追加・取り外し・曲順、ジャケットの登録・差し替え
  • 掲載停止と再開（曲・アルバム。データは消えない）、掲載停止中のものを管理一覧から外す・戻す、削除した登録の復元
  • サイトの文言：トップの一文、ヒストリー／その他の作品の見出し・説明文・末尾の文、アーティスト紹介、メッセージ欄の説明文、音源非公開の曲ページの文
  • PRIVATE：歌詞・よみがなの登録、招待者パスワードの変更（左の「PRIVATE管理」）。音源の追加・差し替えは PRIVATE の管理画面 /admin
  • 全楽曲の公開状況の記録（公開区分・歌詞の範囲・配信先）

AIへの依頼が必要なもの

  • ページの構成・デザイン・色・演出、アルバムの特設デザイン（背景・題字・写真の構成）
  • メニュー・ボタン・欄の名前、メッセージの送信フォーム
  • ディスク別・複数作品の構成の作品（Favorite Track・SOLO WORKS など）の曲目構成
  • 曲の公開日（新着順は掲載した日で自動）、上記以外のリンク
  • 音源・データの完全な削除、一般視聴ページへの曲の掲載（Producer の承認後に担当が反映）

一覧のいちばん下にも「固定（変更はAIに依頼）」があります。変更したいときは、Claude Code などのAIに「〇〇を変えたい」と依頼してください。PRIVATEの音源の追加・差し替えは、管理メニューの「PRIVATE音源の登録・管理」でPRIVATEの管理画面（管理者パスワードで入る）を開いて行います。
