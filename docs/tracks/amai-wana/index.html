目の前にぶら下がったお金と贅沢な暮らし。怪しいと分かっていながらも、誘惑に負けて抜け出せなくなる男の姿を、軽快な言葉遊びとユーモアで描いた一曲。 忠告する側と誘惑に揺れる側の掛け合いが面白く、まるで短編コメディを見ているような展開が楽しめる。 実際の仲間同士の会話から、その日のうちに生まれたという制作背景も魅力的。 何気ない会話をそのまま物語に変えてしまう、 PIP POPPERらしい遊び心が詰まった作品だ。
