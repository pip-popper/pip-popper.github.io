Be myself

PIP POPPER

AI ImpressionAIの感想

「さよならはとても強い雨」と、別れの痛みを雨に重ねて描いたヴィジュアル系ロック。男性ボーカルがひとりで歌い上げる。嘘も真実も流し去る雨の下で立ち尽くし、涙が枯れてもなお「覚めないで欲しい」と夢にすがる姿が切ない。それでも繰り返される「届けたいよ」という想いは、影を背負い、傷つきながらも走り続ける決意へと変わっていく。最後に英語で放たれる「I want to be myself」は、喪失を抱えたまま自分自身として生きようとする宣言として響き、悲しみだけでは終わらない一曲にしている。
